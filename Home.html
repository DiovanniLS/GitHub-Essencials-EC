O que é Git e GitHub?

Git é uma ferramenta de versionamento de código que permite salvar versões e alterações de um arquivo, possibilitando melhor manutenção e colaboração em equipe.

Git Pull, Git Push, Commit... para que servem?

Para começar, é preciso usar o comando git init, ou seja, iniciar um repositório Git no seu projeto.

Depois disso, devemos fazer o primeiro git commit para registrar as alterações. Posteriormente, podemos enviá-las ao GitHub com o comando git push.

GitHub

GitHub é uma plataforma online para armazenar repositórios Git. Ela permite visualizar todas as versões e alterações feitas no código ao longo do tempo.

O GitHub é gratuito e público por padrão, mas é possível criar repositórios privados para manter seu código restrito.

Principais comandos

  • git init: Inicia o repositório Git, deixando os arquivos visíveis para a ferramenta.
  • git commit: Registra as alterações feitas no repositório local.
  • git push: Envia os arquivos para o repositório GitHub.
  • git pull: Baixa e mescla arquivos do GitHub para seu repositório local.
