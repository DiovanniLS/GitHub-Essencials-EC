O que é Git e Github?

Git é uma ferramenta de versionamento de código, onde você pode salvar versões e alterações de um arquivo. O que possibilita uma melhor manuteção, e melhor trabalho em equipe.

GitPull, GitPush, Commit.. para que serve?

Para iniciarmos, é preciso dar Git init, ou seja, deixar o arquivo visível para a ferramenta git para podermos utilizar suas ferramentas.

depois de iniciar, devemos dar o primeiro "Commit" ou seja, jogar os arquivos dentro do git, e posteriormente jogá-los no Github.

Github:

GitHub é o local onde podemos armazenar nossos arquivos online, é uma "galeria" enorme de arquivos. nele podemos visualizar todas as versões e alterações que foram feitas no código ao longo do tempo e foram jogadas na plataforma.

Github é uma plataforma livre e pública, então todos os códigos da comunidade estão disponíveis ao público(exceto se colocado como privado)

Comandos:

  • Git init: Inicia o repositório git, deixando os arquivos visíveis para a ferramenta;
  • Git Commit: joga os arquivos para o repositório do git. a cada mudança é necessário dar commit;
  • Git Pull: joga os arquivos para o repositório Github;
  • GitPush: pega arquivos de algum repostório GitHub.
